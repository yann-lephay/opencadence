# Squat libre — prototype média

Statut : `PASS PROTOTYPE`, non intégré, non publiable et non marqué `ready`.

Le QC retient les cases 1 à 6 pour la descente, puis les mêmes poses en ordre
inverse. Les cases 7–8 ajoutent une profondeur peu utile et davantage de dérive ;
la remontée indépendante 9–16 est écartée pour éviter le scintillement de
cadrage et de morphologie.

La boucle utilise six poses distinctes et onze étapes visibles sur 3,27
secondes, sans interpolation ni zoom. La trame sur le corps reste une
réserve avant release.
