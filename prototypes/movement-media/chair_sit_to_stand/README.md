# Lever de chaise — prototype média

Statut : `REJETÉ POUR MONTAGE`, non intégré et non marqué `ready`.

La planche V01 contient une séquence corporelle récupérable, mais les pieds et
la géométrie de la chaise dérivent indépendamment. Aucun montage n'est produit
à partir de cette version. Une nouvelle planche doit verrouiller la relation
entre pieds, assise et caméra.

La V02 améliore la séquence corporelle, mais échoue encore sur le même
invariant : la chaise et les pieds se déplacent entre les poses alors qu'ils
doivent rester fixes. Un recadrage global ne peut pas verrouiller à la fois le
décor, la chaise et les appuis. La V02 reste donc une preuve d'échec utile, pas
une source de montage.
