# Soulevé de terre roumain avec haltères — prototype média

Statut : prototype interne à corriger, non intégré, non publiable et non marqué
`ready`.

La planche V01 fournit une séquence récupérable avec les cases
`1 → 14 → 2 → 4 → 5 → 6 → 7 → 9`, puis le retour par les mêmes poses en ordre
inverse. La case 14 atténue le saut initial entre la station debout et la
première charnière.

La boucle vise environ 3,5 secondes avec huit poses distinctes sur l'aller,
sans interpolation ni zoom.

Réserves avant validation produit :

- retirer les haltères inutilisés visibles dans le décor ;
- alléger nettement la trame sur le corps, les mains et les haltères ;
- confirmer avec un professionnel du mouvement la flexion des genoux et la
  neutralité du haut du dos dans les positions basses.
