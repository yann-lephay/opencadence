# Rowing penché avec deux haltères — prototype média

Statut : `REJETÉ POUR MONTAGE` après les planches V01 et V02. Aucun média n'est
intégré, publiable ou marqué `ready`.

Les deux planches permettent seulement quatre phases crédibles : suspension,
amorce, mi-course et contraction. L'angle du buste, les pieds et les deux
haltères restent assez cohérents, mais aucune cinquième pose ne comble le saut
entre l'amorce et la mi-course.

Aucune interpolation ni microvariation ne doit être présentée comme une phase
supplémentaire. Une future source doit fournir une pose nette de flexion du
coude intermédiaire sans modifier la charnière ni les appuis.
