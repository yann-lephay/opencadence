# Pont fessier — prototype média

Statut : `PASS PROTOTYPE`, non intégré, non publiable et non marqué `ready`.

Le QC retient les cases `1 → 4 → 5 → 6 → 7 → 8` pour la montée, puis les
mêmes poses en ordre inverse. Les cases 2–3 et 9–15 sont des doublons ou un
retour moins stable. La case 16 est rejetée : les jambes sont étendues et le
mouvement n'est plus un pont fessier comparable.

La boucle utilise six poses distinctes sur environ 3,2 secondes, sans
interpolation ni zoom. La palette correspond au branding ; la matière sur le
corps devra être atténuée pour un média de release.
